Arithmetic Sequences

Look for the same change between terms.

aₙ = a₁ + (n − 1)d

Example

Find the 10th term: 5, 9, 13, 17...

a₁ = 5. The common difference is d = 4. So a₁₀ = 5 + (10 − 1)(4) = 41.

Geometric Sequences

Look for the same multiplier between terms.

aₙ = a₁ · rⁿ⁻¹

Example

Find the 7th term: 2, 6, 18, 54...

a₁ = 2. The common ratio is r = 3. So a₇ = 2 · 3⁶ = 1458.
