Arithmetic

Add or subtract the same amount.

4, 7, 10, 13...

common difference = +3

Geometric

Multiply or divide by the same amount. Most of the time, start by asking: “What are we multiplying by?”

3, 6, 12, 24...

common multiplier = ×2
Assessment mindset: Do not start with the formula. First classify the pattern. Add/subtract check first. Multiply check second. Use division only as a quick way to confirm the multiplier when it is not obvious.

How to Identify the Type Fast

Before solving, students should ask: “What stays the same each step?”

Arithmetic traits

Look for equal differences

Ask: What are we adding or subtracting each time?

4, 7, 10, 13
+3, +3, +3

If the same amount is added or subtracted each time, it is arithmetic. The formal name is common difference.

Example: 8, 12, 16, 20
+4, +4, +4
Arithmetic, common difference = 4
Geometric traits

Look for equal multipliers

Ask: What are we multiplying by each time?

3, 6, 12, 24
×2, ×2, ×2

If the same multiplier is used each time, it is geometric. The formal name is common ratio.

Confirming trick:
6÷3=2, 12÷6=2, 24÷12=2
Geometric, common multiplier / common ratio = 2
Neither traits

No steady add or multiply

If the add/subtract pattern does not stay the same and the multiply pattern does not stay the same, it is probably neither.

Example: 1, 4, 9, 16
Adding: +3, +5, +7
Multiplying: not constant
Neither arithmetic nor geometric
Common traps

Do not get fooled

Negative and fractional multipliers count.

81, 27, 9, 3 is geometric because it multiplies by 1/3 each time. It can also be described as dividing by 3.

Multiplication is the main idea. Division is just a way to check the multiplier.

Quick identification checklist

Check addition/subtraction first. Same amount? Arithmetic.

If not, check multiplication. Same multiplier? Geometric.

Use division only to confirm the multiplier: next term ÷ previous term.

If neither test works, mark it neither unless the problem gives a different rule.

Only after classifying, choose the formula or shortcut.

Arithmetic Sequences

Look for the same change between terms. That repeated change is the common difference, d.

aₙ = a₁ + (n − 1)d

Example

Find the 10th term: 5, 9, 13, 17...

Pattern first: +4, +4, +4. The common difference is d = 4. Formula route: a₁₀ = 5 + (10 − 1)(4) = 41.

Traits to notice

Straight-line growthSame add/subtractConstant difference

Arithmetic sequences connect directly to linear functions because the rate of change is constant.

Fast path: If the term you need is close, count jumps instead of writing the full formula. For 5, 9, 13, 17... the 10th term is 6 jumps after the 4th term: 17 + 6(4) = 41.

Geometric Sequences

Look for the same multiplier between terms. Students should think multiply first. The formal math term for that multiplier is common ratio, r.

aₙ = a₁ · rⁿ⁻¹

Example

Find the 7th term: 2, 6, 18, 54...

Pattern first: 2 × 3 = 6, 6 × 3 = 18, 18 × 3 = 54. So the common multiplier is ×3. Mathematicians call that the common ratio, r = 3.

Fast route: keep multiplying: 54 × 3 = 162, 162 × 3 = 486, 486 × 3 = 1458. So a₇ = 1458.

Formula route: a₇ = 2 · 3⁶ = 1458.

Traits to notice

Multiplicative growthSame multiplierCommon ratio is the formal name

Geometric sequences connect to exponential functions because the multiplier is constant.

Fast path: If answer choices are given or the target term is nearby, multiply forward. Save the exponent formula for far-away terms or formula-matching problems.
