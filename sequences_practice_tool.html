How to Tell the Difference Quickly

The fast Regents move: check whether the same number is being added/subtracted each time or the same number is being multiplied each time.

Arithmetic Sequence

Look for a constant difference.

  • Example: 5, 8, 11, 14, ...
  • Each term adds 3.
  • Common difference: d = 3
  • Quick check: subtract neighboring terms.

Geometric Sequence

Look for a constant ratio.

  • Example: 3, 6, 12, 24, ...
  • Each term multiplies by 2.
  • Common ratio: r = 2
  • Quick check: divide neighboring terms.

Formula Clues

  • Arithmetic explicit: aₙ = a₁ + (n − 1)d
  • Arithmetic recursive: aₙ = aₙ₋₁ + d
  • Geometric explicit: aₙ = a₁ · rⁿ⁻¹
  • Geometric recursive: aₙ = r · aₙ₋₁

Test-Taking Shortcut

Before using a formula, identify the pattern:

  • If the gaps match → arithmetic.
  • If the multipliers match → geometric.
  • If neither matches → it may not be either one.
