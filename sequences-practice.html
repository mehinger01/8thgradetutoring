Fast Pattern Check

Arithmetic means the same amount is added or subtracted each time. Geometric means the same number is multiplied each time. The fastest Regents move is: check differences first, then ratios.

Arithmetic

Look for a constant difference, d.

aₙ = a₁ + (n − 1)d

Example: 4, 7, 10, 13 adds 3 each time.

Geometric

Look for a constant ratio, r.

aₙ = a₁(r)ⁿ⁻¹

Example: 3, 6, 12, 24 multiplies by 2 each time.

Difficulty ramps up

Next terms → common difference/ratio → nth term → missing terms → formula choice → mixed identification.

Adaptive rule

Two correct in a row raises the level. Three misses in a row lowers it.

Arithmetic Practice

Checklist

Subtract consecutive terms. If the difference stays the same, use aₙ = a₁ + (n − 1)d.

Geometric Practice

Checklist

Divide consecutive terms. If the ratio stays the same, use aₙ = a₁(r)ⁿ⁻¹.

Mixed Identification

Strategy

Do not guess. Differences first. Ratios second. If both fail, it is neither.
