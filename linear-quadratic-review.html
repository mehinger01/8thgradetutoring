Big Picture

Functions are the umbrella idea. Lines and quadratics are special kinds of functions. The Regents-style move is to recognize the pattern from a graph, table, equation, or situation.

Function

One input → one output

Each x-value can only have one y-value.

Linear

y = mx + b

m is slope. b is the y-intercept.

Standard Linear

Ax + By = C

Useful for intercepts and for rearranging into slope-intercept form.

Quadratic

y = ax² + bx + c

The graph is a parabola. The sign of a decides up or down.

Functions: Regents Skill Map

A function is a rule or relationship where every input has exactly one output. That idea can show up as ordered pairs, a table, an equation, a graph, or a word problem.

Function rule: each x-value gets no more than one y-value.
Vertical Line Test

Graph check

If any vertical line hits the graph more than once, it is not a function.

Tables

Input/output check

Look for repeated x-values. Repeated y-values are okay. Repeated x-values with different y-values are not okay.

Function: (1,4), (2,4), (3,7)
Not a function: (1,4), (2,5), (1,8)
Function Notation

f(x)

f(3) means “the output when x = 3.” It does not mean f times x.

If f(x)=2x+5, then f(3)=2(3)+5=11.
Domain & Range

Inputs and outputs

Domain is the set of possible x-values. Range is the set of possible y-values.

For points (1,2), (3,8), (5,8): domain = {1,3,5}; range = {2,8}.

Quick Check

Is this a function? {(2,5), (3,7), (2,9)}

Not a function. The input x = 2 has two different outputs: 5 and 9.

Slope Calculation

m = (y₂ − y₁) / (x₂ − x₁)

Think: vertical change over horizontal change. Or, in student language: how much up/down for each move right.

Example

Find the slope through (2, 3) and (6, 11).

m = (11 − 3) / (6 − 2) = 8 / 4 = 2. The line goes up 2 for every 1 step right.

Positive Slope

Line rises left to right.

Negative Slope

Line falls left to right.

Zero Slope

Horizontal line: y = a number.

Undefined Slope

Vertical line: x = a number.

Slope-Intercept Form

y = mx + b

m tells the steepness. b tells where the line crosses the y-axis.

Example

For y = 3x − 4, the slope is 3 and the y-intercept is −4.

Start at −4 on the y-axis. Then use the slope 3, which means rise 3 and run 1. Plot another point and draw the line.

Common Misread

In y = -2x + 5, the slope is -2, not 5. The 5 is the y-intercept.

Standard Form for Lines

Ax + By = C

Standard form can be changed into slope-intercept form by solving for y.

Example

Change 2x + y = 7 into slope-intercept form.

Subtract 2x from both sides: y = -2x + 7. The slope is -2 and the y-intercept is 7.

x-intercept trick

Set y = 0 and solve for x.

y-intercept trick

Set x = 0 and solve for y.

Quadratic Equations

Standard form: y = ax² + bx + c

A quadratic has an x² term. Its graph is a parabola.

If a > 0

The parabola opens up like a smile.

If a < 0

The parabola opens down like a frown.

c-value

In y = ax² + bx + c, c is the y-intercept.

Zeros / solutions

Where the graph crosses the x-axis.

Factored Form Connection

If y = (x − 3)(x + 2), the zeros are x = 3 and x = -2.
